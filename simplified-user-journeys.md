# Simplified User Journeys - Step-by-Step

## Guest Mode Journey

**Step 1:** Land on HomeScreen → Click "Continue as Guest"  
**Step 2:** Auto-redirect to DiscoverScreen (skip Navigation Hub)  
**Step 3:** Browse profiles - see name/age/location only (15 swipes max)  
**Step 4:** Click card = detail prompt | Thumbs up = like prompt  
**Step 5:** At 15 swipes = hard stop, must create account or exit  
**Result:** Limited preview to encourage sign-up

---

## Signed-In User Journey - First Time

**Step 1:** HomeScreen → "Sign In" → Click "Create one here"  
**Step 2:** CreateAccountScreen → Enter email/password → Submit  
**Step 3:** NavigationScreen hub → Click "Edit My Public Profile"  
**Step 4:** Complete profile - photos, bio, interests, prompts, preferences  
**Step 5:** Return to hub → Click "Discover" tile → Unlimited swiping  
**Result:** Full access to all features

---

## Signed-In User Journey - Returning User

**Step 1:** HomeScreen → "Sign In" → Enter credentials  
**Step 2:** NavigationScreen hub appears with profile name  
**Step 3:** Choose action: Discover | Messages | Connections | Fave Profiles | Edit Profile  
**Step 4:** Navigate freely with "Start Over" or [LOGO] to return to hub  
**Step 5:** Sign Out when done  
**Result:** Seamless access to all app features

---

## Discovery Flow - Signed-In

**Step 1:** NavigationScreen → Click "Discover" tile  
**Step 2:** DiscoverScreen → View profile card with full info  
**Step 3:** Click card for ProfileDetailScreen OR swipe with thumbs  
**Step 4:** Thumbs up → Save to favorites, possible match notification  
**Step 5:** Match = 3sec overlay → "Send Message" or "Keep Discovering"  
**Result:** Unlimited browsing, matching, saving

---

## Messaging Flow - Signed-In

**Step 1:** NavigationScreen → Click "View My Messages"  
**Step 2:** ViewMessagesScreen → See all conversations list  
**Step 3:** Click conversation → ConversationScreen with full chat  
**Step 4:** Type message → Click send (✈️) → Message appears  
**Step 5:** ← Back to inbox OR ← Start Over to hub  
**Result:** Easy conversation management and messaging

---

## Profile Management Flow - Signed-In

**Step 1:** NavigationScreen → Click "Edit My Public Profile"  
**Step 2:** EditPublicProfileScreen → Update any fields (photos/bio/interests/prompts/preferences)  
**Step 3:** Click "Save Changes"  
**Step 4:** Return to NavigationScreen with updated profile  
**Step 5:** Changes visible to all matches immediately  
**Result:** Complete profile control

---

## Connections Flow - Signed-In

**Step 1:** NavigationScreen → Click "Connections" tile  
**Step 2:** ConnectionsScreen → View all mutual matches  
**Step 3:** Each match shows: photo, name, age, location, match date  
**Step 4:** Click "View Profile" OR "Send Message" OR "Remove Connection"  
**Step 5:** Navigate as needed  
**Result:** Organized match management

---
